# When Stuck: Fallbacks

The symptom-to-technique table is in `SKILL.md`; this file holds what to do when the matched technique gave nothing. One technique at a time: stacking hides which one helped, and a null result is worth logging.

## If Nothing Works

Fallback checks, in order:

1. **Reframe** — am I solving the right problem?
2. **Explain to someone else** — rubber-duck reveals hidden assumptions.
3. **Simplify scope** — smaller version first.
4. **Question constraints** — real or assumed?
5. **Reroute** — if the block is "not enough evidence about cause," switch to `mk:sequential-thinking`. If it's a multi-perspective trade-off, switch to `mk:party`.
