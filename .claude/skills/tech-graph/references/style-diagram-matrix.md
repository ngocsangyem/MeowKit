# Style Choice by Diagram Type

Default to Style 1 (Flat Icon) when the user names no style. Style 8 (Dark Luxury) is hand-authored SVG only. Use these short lists to pick; a style that is not listed is a fair choice.

## Best

- **Architecture, data flow, network topology:** 1 Flat Icon, 2 Dark Terminal, 3 Blueprint; 8 Dark Luxury for premium docs.
- **Class, ER, state machine, use case:** 3 Blueprint, 4 Notion Clean, 6 Claude Official, 7 OpenAI.
- **Sequence:** 3 Blueprint, 4 Notion Clean, 6 Claude Official, 7 OpenAI.
- **Flowchart:** 1 Flat Icon (default); the others are all workable.
- **Mind map:** 1 Flat Icon, 4 Notion Clean, 5 Glassmorphism, 8 Dark Luxury.
- **Comparison or feature matrix:** 1 Flat Icon, 4 Notion Clean, 6 Claude Official, 7 OpenAI.
- **Timeline or Gantt:** 1 Flat Icon, 4 Notion Clean.
- **Agent or memory architecture:** 1, 2, 5, 6, 7 and 8 all fit.

## Avoid

- **5 Glassmorphism** for structure-heavy diagrams (class, ER, sequence, data flow, state, use case, comparison): the glass effects distract from the content.
- **3 Blueprint** for mind maps (the grid fights a radial layout) and for comparison tables (the grid conflicts with table layout).
- **2 Dark Terminal and 8 Dark Luxury** for use case diagrams (stick figures disappear on a dark background).
- **8 Dark Luxury** for UML, comparison tables and use case diagrams; use it only when the context is premium editorial.
