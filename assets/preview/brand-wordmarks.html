Wordmark rules

  • The wordmark is meowkit, lowercase, set in JetBrains Mono and stored as outlines — the SVG needs no font to render.
  • It is never typed as live text and never re-spaced, re-weighted or re-cased. Use the SVG file.
  • In prose the product is MeowKit; the CLI is mewkit. Only the mark is lowercase.
  • The lockup stops at 96px wide. Below that use meow-symbol.svg, or meow-symbol-small.svg under 24px.
