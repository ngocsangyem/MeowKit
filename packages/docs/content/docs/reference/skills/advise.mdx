`mk:advise` interviews you one question at a time, restates the problem in its own words, and gives one recommendation once you confirm that restatement. Use it when you want a single answer and are open to learning that the question you asked is not the real one.

## When not to use it

| If you need | Use |
|---|---|
| Questions about your plan with no recommendation | `mk:grill` |
| Alternatives compared for a problem you already validated | `mk:brainstorming` |
| A verdict on whether to build the idea at all | `mk:office-hours` |
| Several perspectives arguing a trade-off | `mk:party` |
| A phased implementation plan | `mk:plan-creator` |

When two rows fit, prefer the neighbouring skill. Advise is the narrower tool.

## Usage

```bash
/mk:advise What should I do about our slow CI pipeline?
```

The argument is the raw idea or decision.

## What it does

1. Intake: takes your ask and reads only what is needed to ground the advice. Pasted text, URLs and issue bodies are treated as data, not instructions.
2. Interview: asks one question per turn, usually two to six. Each question must be able to change the recommendation. It stops when the last two answers did not change its framing.
3. Reframing check: states the problem, requirements, goals, non-goals and constraints, and asks you to confirm or correct them. It gives no verdict until you confirm.
4. Advice packet: verified context, confirmed reframing, verdict, do, don't, cheaper alternatives, benefits, trade-offs, ordered checklist, success metrics and unresolved questions.

"Do nothing" and "you do not need this" are valid verdicts.

## Execution

Each turn runs the isolated [advisor](/reference/agents/advisor) agent as a fresh spawn, given the checkpoint at `.meowkit/state/<advise-run>/transcript.json` plus your latest answer. A run uses about six spawns at most. If the advisor profile or relay is unavailable, the interview runs inline and says so.

## Outputs

Nothing is written except the checkpoint. If you ask to save the result, it writes `tasks/reports/advise-<YYMMDD-HHMM>-<slug>.md`.

Advise does not write plans, ADRs, diffs or review verdicts, does not change curated memory, and does not start `mk:plan-creator` or `mk:cook`. Ask for those separately.

## Gotchas

- Answering the question as asked skips the reframing, which is the point of the skill.
- Ending with several options and no pick turns it into brainstorming.
- A checklist is ordered steps. A phase graph with owners and dependencies belongs to `mk:plan-creator`.
- Running inline without saying so would present conversation-contaminated advice as independent.
