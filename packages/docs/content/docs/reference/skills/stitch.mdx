## What it does

`mk:stitch` generates a high-fidelity UI design from a text prompt through the Stitch service, then exports Tailwind HTML, a PNG screenshot and a `DESIGN.md` that `mk:frontend-design` implements. It is for a new design with no source to start from. It is disabled without a Stitch API key.

## When not to use it

| Need | Use |
|---|---|
| A design already exists in Figma | `mk:figma` |
| Designing or building from text without Stitch | `mk:frontend-design` |

## Setup

Set `STITCH_API_KEY` (an `sk_...` key from the Stitch settings page) in the project env file, then install the scripts once:

```bash
cd ${CLAUDE_SKILL_DIR}/scripts && npm install
```

The scripts need `tsx`. Each one stops with exit 1 before any network request if the key or `tsx` is missing. `references/stitch-setup.md` covers optional variables and MCP setup.

## Usage

| Task | Command |
|---|---|
| Check quota | `npx tsx ${CLAUDE_SKILL_DIR}/scripts/stitch-quota.ts check` |
| Generate | `npx tsx ${CLAUDE_SKILL_DIR}/scripts/stitch-api-call.ts generate "<prompt>"` |
| Export and write | `npx tsx ${CLAUDE_SKILL_DIR}/scripts/stitch-api-call.ts export <screen-id> \| npx tsx ${CLAUDE_SKILL_DIR}/scripts/stitch-write-output.ts` |

Generate returns `screenId`, `projectId`, `imageUrl` and quota data. The skill shows you the `imageUrl` and asks for your approval before exporting.

## Steps

1. Check quota. Exit code 2 means it is exhausted, and the skill routes to `mk:frontend-design`.
2. Generate, review the screenshot with the user, then export and write.
3. Hand `DESIGN.md` to `mk:frontend-design`.

Outputs go under `tasks/designs/`. See `references/stitch-operations.md` for the exact paths and `references/design-to-code-pipeline.md` for variants and iteration.

## Limits

The export is HTML and Tailwind only, with no React, Vue or Svelte. Layouts are not responsive and there are no animations. Quota is tracked locally and can differ from real usage.

## Gotchas

- If you hit `RATE_LIMITED` while the tracker shows credits, run `stitch-quota.ts reset`. Quota limits and paid tiers change, so read `references/quota-management.md` before deciding on quota.
- The optional MCP setup stores the API key in `.claude/.mcp.json`. Do not commit it. The kit's `.gitignore` covers it.
- `stitch-write-output.ts` accepts only Google CDN domains. If Stitch changes domains, update `ALLOWED_CDN_SUFFIXES` in that script.
