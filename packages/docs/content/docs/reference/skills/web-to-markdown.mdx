## What it does

`mk:web-to-markdown` fetches an arbitrary external page, such as a blog post, RFC or issue, and returns clean markdown. The fetched text is treated as data and is scanned for injection before it is returned. It fires when you give a URL in chat, and other skills such as `mk:intake` can delegate to it.

## When not to use it

| Need | Use |
|---|---|
| Library or framework documentation | `mk:docs-finder` |
| Interactive browser testing | `mk:agent-browser` |
| Playwright test automation | `mk:playwright-cli` |
| Sensitive or internal URLs | The host runtime's built-in `WebFetch` |

## Usage

```
<url> [--wtm-accept-risk] [--wtm-approve]
```

| Flag | Effect |
|---|---|
| (none) | A direct fetch for a URL you gave. |
| `--wtm-accept-risk` | Required when another skill delegates a fetch. Without it the call fails with `ERROR: cross-skill delegation requires --wtm-accept-risk flag`. |
| `--wtm-approve` | Used with `mk:docs-finder` to skip its Context7, Context Hub and WebSearch tiers and fetch the URL directly. |

## Protections

- Only `http` and `https` are allowed. Private, loopback and link-local addresses are blocked, and redirects are re-checked.
- Responses are capped at 10 MB.
- Every return is wrapped as data, including previews.
- The injection scanner checks more than 50 patterns plus encodings (base64, ROT13, Unicode, zero-width characters) and warns on context flooding. A hit stops the fetch and quarantines the content. No flag overrides it, and you inspect the quarantine file yourself.
- Secrets are scrubbed from the content and the URL before anything is written to disk, and the written file is scanned again with `injection-audit.cjs`.
- The `privacy-block.cjs` hook enforces the SSRF rules and blocks reads of the cache and manifest.

`references/security.md` has the full threat model.

## Setup

```bash
mewkit skill env web-to-markdown
```

This installs the packages in `scripts/requirements.txt`. JavaScript rendering is optional. It needs Playwright and Chromium (about 200 MB) installed, `MEOWKIT_WEB_FETCH_JS=1` set, and `js=True` passed in the call. All three must be in place.

## Gotchas

- Without Playwright, JavaScript-rendered pages return an error that points to `.claude/hooks/lib/setup-workflow --system-deps`.
- `robots.txt` is respected with a 24 hour cache. Overriding it needs a manual action from you.
- Fetched reports are kept under `.meowkit/cache/web-fetches/` and are not cleaned up automatically. Remove them with `rm -rf .meowkit/cache/web-fetches/*`.
- The secret scrub does not catch names, emails or user IDs in page text. Treat cached reports as sensitive.
- File names are hashed. Search through the manifest `index.jsonl`, which sits behind the privacy block.
