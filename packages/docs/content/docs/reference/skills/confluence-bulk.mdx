`mk:confluence-bulk` forks the `confluence-bulk` agent to change many Confluence pages at once: bulk label, bulk move or bulk delete. The agent always runs a dry run first, then asks you to confirm, then executes. It refuses to skip the dry run.

## When not to use it

| If you need | Use |
|---|---|
| One page | [`mk:confluence-page`](/reference/skills/confluence-page) |
| Comments, attachments or watchers | [`mk:confluence-collaborate`](/reference/skills/confluence-collaborate) |
| Finding the pages with CQL | [`mk:confluence-search`](/reference/skills/confluence-search) (same CQL sanitizer) |

## Usage

Ask in plain words: "bulk update N pages", "mass label", "delete every page matching CQL", "bulk-move pages from SPACE-A to SPACE-B", "bulk-label every page in space ENG with 'archive'".

## What it does

1. Runs the operation with `--dry-run`.
2. Shows the `would_*` JSON keys, the impacted count and the first five page titles.
3. Waits for an explicit "yes" and a typed confirmation token such as `DELETE 47 PAGES`.
4. Runs it again without `--dry-run` and with `--yes`.

If the impacted count differs by more than 5 percent between the dry run and the execution, the agent reports it as a concern in its status block.

| Operation | Dry-run form |
|---|---|
| Label | `bulk label add --cql "$SAFE_CQL" --label archive --dry-run` |
| Move | `bulk move --cql "..." --target-parent-id 99999 --dry-run` |
| Delete | `bulk delete --cql "..." --dry-run` |

All run through the `confluence-as` wrapper. `--max-pages` defaults to 100, and a higher value needs an explicit override and extra confirmation. `confluence-as` can apply its own cap, typically around 200.

Details are in `references/safety-checklist.md` (pre-flight checks) and `references/dry-run-protocol.md` (the ceremony with example transcripts). Safety tiers are in `../confluence/references/safety-framework.md`.

## Gotchas

- Bulk delete moves pages to the trash. Restoring needs the Confluence UI. There is no bulk restore.
- Operations are not transactional. After a partial failure (rate limit, per-page permission error) the completed count is shown, and the fix is to re-run with `id NOT IN (<completed>)`.

## Agent

[`confluence-bulk`](/reference/agents/confluence-bulk) takes untrusted CQL input and makes a high-impact state change, so the dry-run ceremony is the safeguard for blast radius.
