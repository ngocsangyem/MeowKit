`mk:confluence-page` forks the `confluence-page` agent for operations on one Confluence page: create, get, update, delete, hierarchy (children, ancestors, descendants), version list and restore, copy and move. It calls `confluence-as` through the wrapper script `.claude/skills/confluence/scripts/confluence-as.sh`.

## When not to use it

| If you need | Use |
|---|---|
| Changes across 10 or more pages | [`mk:confluence-bulk`](/reference/skills/confluence-bulk) |
| Spec analysis | [`mk:confluence-spec-analyst`](/reference/skills/confluence-spec-analyst) |
| Comments, attachments, labels, watchers | [`mk:confluence-collaborate`](/reference/skills/confluence-collaborate) |
| CQL search or listing spaces | [`mk:confluence-search`](/reference/skills/confluence-search) |

## Usage

Ask in plain words: "create a page in ENG titled 'Q3 Roadmap' with body from /tmp/draft.md", "create an RFC page in ENG from the rfc template", "show me page 12345 in storage format", "set title to 'Q3 Roadmap (final)' on page 12345", "list children of page 12345 with depth 2", "copy page 12345 to SPACE".

| Operation | Safety tier | Wrapper form |
|---|---|---|
| Get | 1 | `page get --page-id 12345` |
| Create | 2 | `page create --space-key ENG --title "..." --content "..."` |
| Create from template | 2 | `page create --space-key ENG --template rfc --title "..."` |
| Update | 3 | `page update --page-id 12345 --title "..."` (shows current against proposed) |
| Delete | 4 | `page delete`, after a dry-run review |
| Children | 1 | `hierarchy children --page-id 12345 --depth 2` |
| Version restore | 3 | `version restore --page-id 12345 --version <n>` |

Run `--help` on a verb for its flags. Tiers are defined in `../confluence/references/safety-framework.md`.

References: `references/page-templates.md` (RFC, runbook and decision record skeletons), `references/field-formats.md` (`storage`, `view`, `export_view`, `atlas_doc_format` and round-trip caveats) and `references/version-restore-guide.md`.

## Gotchas

- Use the wrapper, not raw `confluence-as` output. JSON is guaranteed only after the wrapper's filter.
- The CLI retries POST, so a create on a flaky network can produce duplicates. Before retrying a failed `page create`, list pages with the same title in the space.
- ADF round trips are lossy for panel, expand, mention, emoji, media, decision and task-list nodes. Updating a page that has them can flatten them, and the agent warns first.
- XHTML parsing in the CLI is regex based and can fail silently on malformed or deeply nested storage format. Prefer Markdown through `--content` for new pages.
- `version restore` adds a new version on top of the head. It is not an in-place rollback, and it restores only the body, not title, labels or parent.

## Agent

[`confluence-page`](/reference/agents/confluence-page) takes untrusted page content and changes state, within the Skill Rule of Two.
