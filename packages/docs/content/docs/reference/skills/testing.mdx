## What it does

`mk:testing` holds the testing guides for Phase 2 (Test) and Phase 3 (Build) and supports the `tester` agent. TDD is opt-in. With `--tdd` or `MEOWKIT_TDD=1` the cycle is red, green, refactor and failing tests come before implementation. In default mode tests can be written before, alongside or after the code.

## When not to use it

| Need | Use |
|---|---|
| Designing or auditing Vue tests (Vitest, Vue Test Utils, Pinia, router) | `mk:vue-testing-best-practices` |
| Nyquist-style test sampling | `mk:nyquist` |

This skill still owns running tests and the TDD cycle for Vue projects.

## Gotchas

- Tests that mock everything can pass while real service calls fail. Use integration tests for critical paths and mock only external third-party services.
- Coverage can be inflated by trivial assertions such as `expect(true).toBe(true)`. Check mutation score alongside coverage and flag tests with no assertions.
