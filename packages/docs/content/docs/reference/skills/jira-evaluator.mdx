## What it does

mk:jira-evaluator forks the `jira-evaluator` agent ([agent page](/reference/agents/jira-evaluator)). It rates a ticket Simple, Medium or Complex with a likely Fibonacci range, lists inconsistencies and open questions, and saves the evaluation. It never changes Jira. The skill is not enabled by default.

## When to use it

Use it for "evaluate PROJ-123", "analyze ticket complexity for KEY" or "check ticket quality".

| Need | Use instead |
|---|---|
| A story-point estimate | [`mk:jira-estimator`](/reference/skills/jira-estimator), which reads this report |
| Full RCA or media analysis | [`mk:jira-analyst`](/reference/skills/jira-analyst) |

## Signals

The agent considers scope, dependencies, regression risk, requirement clarity, external factors, historical comparison and workflow shape. For workflow shape it reads `tasks/jira-workflows/<workflow-slug>.md` and runs `jira/scripts/fetch-workflow.sh <KEY>` first if the cache is missing. More than 5 statuses with parallel review or QA branches raise coordination cost. The scoring guide is `../jira/references/evaluation-rubric.md`.

## Output

```markdown
## Ticket Evaluation: {ISSUE-KEY}
**Complexity:** {Simple|Medium|Complex} (likely {Fibonacci range}pt)
**Confidence:** {High|Medium|Low}
### Signals
### Issues Detected
### Suggested Actions
### Open Questions
```

The report is saved to `tasks/reports/jira-evaluate-{YYMMDD}-{HHMM}-{ISSUE-KEY}.md`. `mk:jira-estimator`, `mk:planning-engine` and the `mk:cook` plan step can use it. The agent's only write is that report.
