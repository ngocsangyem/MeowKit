## What it does

mk:jira-issue forks the `jira-issue` agent ([agent page](/reference/agents/jira-issue)), which runs `jira-as issue` commands through the env-translating wrapper `jira/scripts/jira-as.sh`. The skill is not enabled by default.

## When to use it

Use it for "create a Bug in PROJ", "show me PROJ-123", "update PROJ-123 priority to High" or "delete PROJ-123".

| Need | Use instead |
|---|---|
| State transitions | [`mk:jira-lifecycle`](/reference/skills/jira-lifecycle) |
| Comments and attachments | [`mk:jira-collaborate`](/reference/skills/jira-collaborate) |
| 10 or more issues | [`mk:jira-bulk`](/reference/skills/jira-bulk) |
| Issue links | [`mk:jira-relationships`](/reference/skills/jira-relationships) |
| Time logging | [`mk:jira-time`](/reference/skills/jira-time) |
| Sprints and epics | [`mk:jira-agile`](/reference/skills/jira-agile) |

[`mk:jira-fields`](/reference/skills/jira-fields) supplies custom field IDs.

## Commands

| Operation | Safety tier | Command |
|---|---|---|
| Get | 1 | `jira-as.sh issue get PROJ-123` |
| Create | 2 | `jira-as.sh issue create --project PROJ --type Bug --summary "..."` |
| Create from template | 2 | `jira-as.sh issue create --project PROJ --template bug --summary "..."` |
| Update | 3 | `jira-as.sh issue update PROJ-123 --summary "..." --priority High` |
| Delete | 4 | `jira-as.sh issue delete PROJ-123` |

`--project` and `--summary` are flags on create. Use `--force` on delete only after reviewing a dry run. `references/cli-idioms.md` under `jira/` lists the verified syntax, and `--help` on each verb gives the full flag list.
