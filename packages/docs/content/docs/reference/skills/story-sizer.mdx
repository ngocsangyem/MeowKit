## What it does

`mk:story-sizer` forks to the `story-sizer` agent. You paste a markdown block of stories, and the agent scores each one with deterministic heuristics and writes a Story Sizing Report. The default mode makes no Jira calls. An opt-in mode can create the tickets afterwards.

## When not to use it

| Need | Use |
|---|---|
| Estimate an existing ticket | `mk:jira-estimator` |
| Score an existing ticket's complexity | `mk:jira-evaluator` |
| Sprint capacity | `mk:planning-engine` |

## Usage

| Invocation | Effect |
|---|---|
| `/mk:story-sizer --paste [--scout] [--story <id>]` | Writes the report only. |
| `/mk:story-sizer --paste --auto-create --project <KEY> [--epic <KEY>]` | After a dry run and one confirmation, creates a ticket per story through `mk:jira-issue`. |

`--scout` does not run `mk:scout`. It reuses scout output already in the session or asks you to run scout first. Without codebase signals the report carries `[NO_CODEBASE_CONTEXT]`.

## How it works

| Stage | File or script |
|---|---|
| Parse the paste into `StoryRecord`s with a SHA-256 source hash | `references/input-adapter.md`, `scripts/parse-paste-stories.py` |
| Score with integer arithmetic over text-derived counts, so the same input gives the same result | `references/sizing-heuristics.md`, `scripts/score-story.py` |
| Render the report | `references/report-writer.md`, `scripts/write-sizing-report.py` |

The heuristics cover complexity dimensions, inconsistency detection, split proposals and a definition-of-ready advisory. The advisory appears only when `mk:agent-detector` loaded its agile story reference in the session. Script paths are relative to `${CLAUDE_SKILL_DIR}`.

## Output

`tasks/reports/story-sizing-{YYMMDD}-{slug}.md`. A rerun on an identical paste asks before it overwrites. Suggested create commands use only `--project`, `--type`, `--summary`, `--story-points`, `--description` and optionally `--epic`, `--components` and `--labels`.

## Auto-create

Five pre-flight checks run first: missing acceptance criteria, prompt-injection patterns, a length cap, a possible duplicate (through `mk:jira-search`) and a source-hash mismatch. If all pass, the skill renders a dry-run table and asks once. The rules are in `references/auto-create-gating.md`.

## Gotchas

- The report header holds the SHA-256 of the exact paste. Editing the paste between sizing and `--auto-create` aborts the run. Paste the new text and rerun `--paste`.
