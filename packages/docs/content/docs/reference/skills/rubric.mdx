## What it does

`mk:rubric` is the API for the rubric library in `.claude/skills/rubric/rubrics/`. The `evaluator` agent and `mk:evaluate` load rubrics through it, and you can call it directly to inspect, compose or validate rubrics.

The library holds the rubrics `code-quality`, `craft`, `design-quality`, `functionality`, `originality`, `product-depth` and `ux-usability`, plus the composition presets `backend-api`, `cli-tool`, `frontend-app` and `fullstack-product`.

## When not to use it

To grade a running build, use `mk:evaluate`. This skill only supplies the rubrics.

## Usage

| Subcommand | Effect |
|---|---|
| `list` | Lists rubrics and presets with their default weight and what they apply to. |
| `load <name>` | Emits one rubric as a prompt-ready block. |
| `compose <preset>` | Emits a preset's member rubrics with a weight table. |
| `validate [path]` | Checks one rubric, or all of them, against `rubrics/schema.md`. |
| `validate --preset [path]` | Checks that a preset's weights sum to 1.0 (within 0.01). |

The scripts behind them:

```bash
${CLAUDE_SKILL_DIR}/scripts/load-rubric.sh --list
${CLAUDE_SKILL_DIR}/scripts/load-rubric.sh design-quality
${CLAUDE_SKILL_DIR}/scripts/load-rubric.sh --preset frontend-app
${CLAUDE_SKILL_DIR}/scripts/validate-rubric.sh
```

Run them from the project root.

## Rubric format

Each rubric has frontmatter (`name`, `version`, `weight_default`, `applies_to`, `hard_fail_threshold`), the required sections in order, at least one PASS and one FAIL anchor example with the counts within one of each other, and at most 200 lines. A loaded rubric prints its intent, criteria, grading table, anti-patterns and few-shot examples. Anti-patterns are fixed: each one fails the rubric whatever the other criteria say.

## Calibration

Add few-shot examples as `references/calibration-guide.md` describes: balanced PASS and FAIL counts, randomised order, and real prior reviews where possible.

## Gotchas

- To add a rubric, drop a `.md` file in `rubrics/`, run `validate-rubric.sh` and add its weight to each preset that should include it.
- Changing a rubric's `weight_default` means rechecking that every preset using it still sums to 1.0.
- Load only the preset a task needs, not the whole library.
