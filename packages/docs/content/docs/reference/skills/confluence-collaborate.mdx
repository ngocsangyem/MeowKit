`mk:confluence-collaborate` forks the `confluence-collaborate` agent to manage the collaboration layer of one page: comments, attachments, labels and watchers. It prefers footer comments and asks before posting an inline comment.

## When not to use it

| If you need | Use |
|---|---|
| Page create, read, update or delete | [`mk:confluence-page`](/reference/skills/confluence-page) |
| A label or other change across 10 or more pages | [`mk:confluence-bulk`](/reference/skills/confluence-bulk) |

## Usage

Ask in plain words: "add comment to page 12345: 'awaiting backend fix'", "list comments on page 12345", "attach /tmp/repro.mp4 to page 12345", "label 12345 as 'rfc'", "remove label 'draft' from page 12345", "watch page 12345", "who watches page 12345?".

| Operation | Safety tier | Wrapper form |
|---|---|---|
| Comment add (footer) | 2 | `comment add --page-id 12345 --body "<text>"` |
| Comment add (inline) | 2 | `comment add --page-id 12345 --inline --selection "<unique anchor>" --body "<text>"` |
| Comment list | 1 | `comment list --page-id 12345` |
| Attachment upload | 2 | `attachment upload --page-id 12345 --file <path>` |
| Attachment download | 1 | `attachment download --attachment-id <aid> --output <path>` |
| Label add | 2 | `label add --page-id 12345 --label rfc` |
| Label remove | 3 | `label remove --page-id 12345 --label draft` |
| Watcher add, remove, list | 2, 3, 1 | `watch add\|remove\|list --page-id 12345` |

Tier 1 is read-only, tier 2 is a reversible single change, tier 3 asks you to confirm first. Tiers are defined in `../confluence/references/safety-framework.md`.

An upload path must be under `$CLAUDE_PROJECT_DIR` or an allowlisted `/tmp/conf-*` prefix. The agent rejects `..` traversal itself and does not rely on the CLI to do it.

References: `references/comment-formats.md` (inline or footer, Markdown or storage format) and `references/attachment-conventions.md` (size limits, allowed types, download paths).

## Gotchas

- An inline comment needs anchor text that is unique on the page. Otherwise Confluence returns a 400-class error.
- Confluence Cloud comments have no internal or public flag. Footer versus inline is the nearest boundary, so footer is the default.

## Agent

[`confluence-collaborate`](/reference/agents/confluence-collaborate) handles untrusted comment, file and label content and changes per-page state. Footer-by-default and path validation are its safeguards.
