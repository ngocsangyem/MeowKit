`mk:clean-code` holds the coding standards MeowKit applies while code is being written: concise, direct and solution-focused. Use it during implementation (Phase 3) or for an ad-hoc quality check at any phase, on any change that adds or modifies logic.

## When not to use it

| If you need | Use |
|---|---|
| Behaviour-preserving cleanup of the finished diff (Phase 3.5) | `mk:simplify` |
| A review of a diff or PR | `mk:review` |

The two complement each other: clean-code applies standards as you write, simplify reduces complexity in completed code.

## Principles

| Principle | Rule |
|---|---|
| SRP | Each function or class does one thing |
| DRY | Extract duplicates and reuse them |
| KISS | The simplest solution that works |
| YAGNI | Do not build unused features |
| Boy Scout | Leave code cleaner than you found it |

## What it does

1. Read the existing code before changing it.
2. Check dependencies: what imports the file, what it imports, which tests cover it, and whether it is a shared component. Edit the file and its dependents in the same task.
3. Apply the standards in `references/coding-standards.md`.
4. Self-check: goal met, all files edited, code works, nothing forgotten.
5. Run the verification scripts.

## Standards

| Area | Rule |
|---|---|
| Variables | Reveal intent: `userCount`, not `n` |
| Functions | Verb and noun: `getUserById()` |
| Booleans | Question form: `isActive`, `hasPermission`, `canEdit` |
| Constants | SCREAMING_SNAKE: `MAX_RETRY_COUNT` |
| Function size | At most 20 lines, ideally 5 to 10 |
| Arguments | At most 3, preferably 0 to 2 |
| Structure | Guard clauses, flat over nested, small functions composed, related code kept close |

If a name needs a comment to explain it, rename it. The skill removes obvious comments, inlines one-line helpers, drops factories for two objects, avoids a `utils.ts` with one function, replaces magic numbers with named constants and splits functions that do too much.

## Gotchas

- A helper for a one-time operation breaks YAGNI. Three similar lines beat a premature abstraction.
- Do not strip try-catch from system boundaries. Remove error handling only for internal calls with a guaranteed contract.
