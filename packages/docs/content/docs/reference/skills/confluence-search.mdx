`mk:confluence-search` forks the `confluence-search` agent for read-side Confluence work: CQL searches, validating CQL, building a query from plain language, listing spaces, saved filters and exporting results. Every user-derived CQL term passes through `../confluence/scripts/cql-sanitize.sh` before it reaches the wrapper.

## When not to use it

| If you need | Use |
|---|---|
| Create, update or delete one page | [`mk:confluence-page`](/reference/skills/confluence-page) |
| A bulk write across many pages | [`mk:confluence-bulk`](/reference/skills/confluence-bulk) |
| Deep analysis of a spec page | [`mk:confluence-spec-analyst`](/reference/skills/confluence-spec-analyst) |

## Usage

Ask in plain words: "find pages updated in the last 7 days in space ENG, top 20", "validate this cql: space = ENG AND title ~ 'Q3'", "list every space I can see", "export the search to /tmp/out.csv", "save a filter named 'My recent specs' with this cql".

| Operation | Safety tier | Wrapper form |
|---|---|---|
| Search | 1 | `search "space = ENG AND title ~ \"roadmap\""` |
| Sanitize a term | 1 | `cql-sanitize.sh "$USER_TERM"` |
| Validate | 1 | `validate "space = ENG"` |
| List or get a space | 1 | `space list --limit 50`, `space get --space-key ENG` |
| Saved filter list or favourite | 1 | `filter list`, `filter favourite --filter-id <id>` |
| Saved filter save | 2 | `filter save --name "..." --cql "..."` |
| Export | 1 | `search "..." --export csv --output /tmp/out.csv` |

CQL is a positional argument on `search`, `validate` and `build`. Everywhere else the wrapper takes flags. Run `--help` on a verb for its flags.

References: `references/cql-patterns.md` (curated templates), `references/cql-reference.md` (operators and functions) and `references/search-examples.md`.

## Gotchas

- The CLI does not expose its own CQL escaping, so `cql-sanitize.sh` is the only guard. Use it for every user-derived term.
- The global `--quiet` flag is declared but does nothing. Redirect stderr when needed.
- The keychain entry name `confluence-assistant` clashes with the upstream Confluence-Assistant-Skills tool. MeowKit uses environment variables only, so it is not affected.
- The CLI keeps an opaque two-level cache. If results look stale, `confluence-as ops cache-clear` is safe.

## Agent

[`confluence-search`](/reference/agents/confluence-search) handles untrusted CQL input. It is read-only on Confluence, and saved filters are its only write.
