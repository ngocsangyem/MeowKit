## What it does

mk:docs-init scouts the codebase with `mk:scout`, then hands the findings to the `documenter` agent, which writes the first documentation set. It generates only the files the project needs.

## When to use it

Use it when `docs/` is missing, empty or holds only stubs, when you ask to initialize or generate docs, or after `mk:bootstrap`. Usage: `/mk:docs-init`.

| Need | Use instead |
|---|---|
| Update docs that already exist | `mk:document-release` |
| Only the agent conventions file (`docs/project-context.md`) | `mk:project-context` |

If populated docs exist, the skill suggests `mk:document-release` and stops. Run `mk:project-context` as well when you want the conventions file, since docs-init does not write it.

## Steps

1. Check whether `docs/` exists and is populated.
2. Scout the codebase with `mk:scout`, skipping `.claude/`, `.git/`, `node_modules/`, `__pycache__/`, `dist/` and `build/`.
3. Merge the scout reports into one context.
4. Delegate to the `documenter` agent to write the files below.
5. Run `wc -l docs/*.md | sort -rn` and flag files over 800 lines.
6. Print the generated files with line counts.

The skill writes documentation only, never code.

## Output

| File | Written |
|---|---|
| `README.md` (300 lines or fewer) | Always |
| `docs/project-overview.md` | Always |
| `docs/codebase-summary.md` | Always |
| `docs/code-standards.md` | Always |
| `docs/architecture/system-architecture.md` | Always |
| `docs/deployment-guide.md` | When CI/CD or Docker config is found |
| `docs/design-guidelines.md` | When frontend code is found |

## Gotchas

- Always scout first. Docs written without findings describe code that does not exist.
- A project under 10 files gets `README.md` and `docs/codebase-summary.md` only.
- `README.md` is for outside readers (setup, usage). `docs/project-overview.md` is for insiders (why it exists, design decisions).
- List entry points in `docs/codebase-summary.md` under "Entry Points".
- Docs drift after the first feature. Run `mk:document-release` after each ship.
