## What it does

mk:jira-lifecycle forks the `jira-lifecycle` agent ([agent page](/reference/agents/jira-lifecycle)) to run `jira-as lifecycle` commands: transitions, assignment, resolve, reopen and versions. `lifecycle transition` takes the issue key and either `--to "Status Name"` or `--id <transition_id>`. The skill is not enabled by default.

## When to use it

Use it for "transition PROJ-123 to In Progress", "mark PROJ-123 as Done with resolution Fixed", "assign PROJ-123 to john.doe", "reopen PROJ-123" or "release version v1.0.0 in PROJ".

| Need | Use instead |
|---|---|
| Create, read, update, delete an issue | [`mk:jira-issue`](/reference/skills/jira-issue) |
| Comments | [`mk:jira-collaborate`](/reference/skills/jira-collaborate), which also supplies transition comment bodies |
| Several issues at once | [`mk:jira-bulk`](/reference/skills/jira-bulk). The agent refuses "assign all my open tickets". |
| Service Management transitions | [`mk:jira-jsm`](/reference/skills/jira-jsm) |

Many workflows require a resolution when moving to Done or Closed. The agent asks for one when it is missing.

## Workflow discovery

Status names and transitions differ per Jira instance, so the agent reads the discovered cache in `tasks/jira-workflows/` before suggesting a transition. If it is missing, the agent runs:

```bash
bash $CLAUDE_PROJECT_DIR/.claude/skills/jira/scripts/fetch-workflow.sh PROJ-123
```

The script tries `admin workflow for-issue PROJ-123` first, which returns the full graph for an admin. On a permission error it falls back to `lifecycle transitions PROJ-123`, which returns only outgoing transitions, and writes a partial cache marked incomplete (`_partial-PROJ.md`). The cache holds:

| Path | Content |
|---|---|
| `tasks/jira-workflows/_schemes/<PROJECT_KEY>.md` | Project to workflow name |
| `tasks/jira-workflows/<workflow-slug>.md` | Full statuses and transitions |

The files in `references/patterns/` (standard, software-dev, jsm-request, incident) show typical workflow shapes. They are not your instance's workflow, so the discovered cache wins.
