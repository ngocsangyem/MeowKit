The security agent audits plans and implementations that touch auth, payments, user data, API endpoints, encryption or another flagged risk surface. The deterministic post-write security scan runs on every write in all modes. This agent adds the deeper audit only where risk calls for it.

It runs on `opus`. Tools: `Read`, `Grep`, `Glob`, `Bash`, `Write`. Per-runtime model pins are on [Agent models](/guide/agent-models).

## When to use

It runs in Phase 2 (review the plan and architecture before code) and Phase 4 (audit the implementation). Use `/mk:cso` for a broader audit.

## What it does

- Applies the platform rules for NestJS, Vue, Swift and Supabase (auth guards, input validation, XSS and CSRF controls, Keychain use, RLS on all tables, service key never on the client).
- Classifies findings as CRITICAL, HIGH (fix before ship), MEDIUM or LOW (advisory). An ambiguous finding is MEDIUM for human review, never LOW.
- Issues a PASS or BLOCK verdict in `tasks/reviews/YYMMDD-<name>-security-verdict.md`. A BLOCK means the change should not ship until it is resolved and re-audited. No hook checks the file, and the verdict says so.
- When auditing a skill that fetches external content, processes untrusted data or writes agent-readable files, produces a PASS, WARN or FAIL table against the ten rules in `.claude/rules/injection-rules.md`. A FAIL on any of them is a BLOCK.
- If it cannot finish an audit it reports what blocks it and issues BLOCK rather than skipping the check.

It owns `.claude/rules/security-rules.md` and `*-security-verdict.md`. The latter is a boundary declared in the agent contract, not a path-scoped write permission.

## Hand-offs

PASS continues the workflow. BLOCK lists the critical findings, required remediation and the agent to fix them. [reviewer](/reference/agents/reviewer) treats a security BLOCK as a FAIL on its Security dimension.

## What it does not do

It writes no production code, tests or docs, and stores no keys or tokens in its output. It does not weaken a security rule without an approved ADR from [architect](/reference/agents/architect).
