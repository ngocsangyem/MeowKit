The jira-dev agent is the executor for `mk:jira-dev` and calls Jira through `.claude/skills/jira/scripts/jira-as.sh`.

It runs on `sonnet`. Tools: `Bash`, `Read`, `Grep`, `Glob`. Per-runtime model pins are on [Agent models](/guide/agent-models).

## When to use

Use it to turn a Jira ticket into a branch name or a pull request body, or to parse and link commits and PRs. Shipping itself is `mk:ship`.

## What it produces

- Branch names as `<type>/<KEY>-<kebab-summary>`, for example `feat/PROJ-123-add-login-rate-limiting`, with the summary capped at about 50 characters.
- PR descriptions: the ticket summary as the title, a description excerpt as the body, acceptance criteria as a checklist and a `Closes PROJ-123` footer. The output can be piped into `gh pr create`.

`mk:ship` may call `dev branch-name <KEY>` during branch creation. This is documented only and has no automatic wiring. It returns the artifact and a ready-to-run `git` or `gh` command.
