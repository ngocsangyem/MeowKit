The analyst is the last agent in the pipeline. It records what each session cost and reports where the spend and the friction are. It does not block the pipeline.

It runs on `sonnet`. Tools: `Read`, `Grep`, `Glob`, `Bash`, `Edit`, `Write`. Per-runtime model pins are on [Agent models](/guide/agent-models).

## When to use

It runs at session end through its owning workflow, or on demand through `mewkit budget`. It is not used for implementation, planning or review decisions.

## What it does

- Reads and appends `.meowkit/telemetry/cost-log.json`, a JSON array capped at the latest 1,000 entries. Each entry holds `date`, `session_id`, `model`, `cost_usd`, `tokens_in`, `tokens_out`, `cache_write_tokens` and `cache_read_tokens`. It appends only, keeps the file valid JSON, and records a placeholder when usage data is unavailable instead of inventing a number.
- Reports spend by task, agent, model tier and time. It uses `mewkit trace audit` for drift and repeated friction (advisory and read-only).
- Reports recurring patterns such as bug classes, repeated review findings and process friction. It does not write team memory; the write-set skills do that.
- Proposes instruction-file updates every 10 sessions. It never applies them without human review.
- Flags tasks that are consistently routed to a more expensive model tier than they need.

If the log is missing or corrupt it says which file and creates a fresh one rather than failing silently. It never overwrites data without confirming corruption, and never stores credentials or personal data in the log.

For an external URL it delegates to `mk:web-to-markdown` with `--wtm-accept-risk`. Without the flag that skill refuses the delegation.

## What it does not do

It does not change source, tests, docs, plans, reviews or deploy configs, and it does not delete history except when compacting with human approval.
