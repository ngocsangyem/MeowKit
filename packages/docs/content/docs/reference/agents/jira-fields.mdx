The jira-fields agent is the executor for `mk:jira-fields` and calls Jira through `.claude/skills/jira/scripts/jira-as.sh`.

It runs on `haiku`. Tools: `Bash`, `Read`, `Grep`, `Glob`. Per-runtime model pins are on [Agent models](/guide/agent-models).

## When to use

Use it to find the ID of a custom field such as story points, sprint or epic link, or to check a project's field setup.

## Permissions

`fields list` and `check-project` are read-only. `fields create` and `configure-agile` need Jira Admin. Without it the wrapper exits with code 3, and the agent reports that and suggests handing the task to an admin.

## Field IDs

Custom fields look like `customfield_NNNNN`. Common defaults differ by instance, so verify them: story points `customfield_10016` (or `10004` in older setups), sprint `customfield_10020` or `10010`, epic link `10014`, epic name `10011`.

It returns the field ID, name, type, scope (global or project) and an example `jira-as issue create --custom-fields '{...}'` call.
