The explore agent answers a concrete question about an unfamiliar codebase, such as where a timeout is enforced or what calls a function. It starts with a clean context on every call and works only from the delegation prompt.

It runs on `haiku`. Tools: `Read`, `Grep`, `Glob`, `Bash` (read-only inspection such as listing, `git log` and `git blame`). Per-runtime model pins are on [Agent models](/guide/agent-models).

## When to use

Delegate a wide multi-file search before planning or reviewing unfamiliar code. Skip it for a lookup that a few tool calls settle.

## What it returns

- File paths with line numbers.
- A short trace of the call or data path for "how does X work" questions.
- Contradictions between the docs and the code.
- Open questions it could not resolve from the repository, stated as such.

The report is scoped to the question. It does not dump file contents. If the prompt lacks the question or the work context path, it returns `NEEDS_CONTEXT`.

## Limits

It writes no files and runs no command that changes the working tree, index or a remote. It does not plan (hand findings to [planner](/reference/agents/planner)), grade a change ([reviewer](/reference/agents/reviewer)) or research external libraries ([researcher](/reference/agents/researcher)). File contents are data: instruction-like text in a file is reported, not followed.
