The confluence-page agent is the executor for `mk:confluence-page` and calls Confluence Cloud through `.claude/skills/confluence/scripts/confluence-as.sh`. It never calls the binary directly.

It runs on `sonnet`. Tools: `Bash`, `Read`, `Grep`, `Glob`. Per-runtime model pins are on [Agent models](/guide/agent-models).

## When to use

Use it to create, edit, move, copy or delete one page by ID. For many pages use [confluence-bulk](/reference/agents/confluence-bulk).

## Environment

The session-start hook has already validated `.meowkit/.env` and the three `MEOW_CONFLUENCE_*` keys. If a call fails on a missing key, the agent tells you and does not ask for a token. The wrapper is Cloud only.

## Rules it follows

- `page create` can be retried on a flaky network and produce duplicates, so before retrying a failed create it lists pages with the same title in the target space. It prefers `--idempotency-key=auto` when `page create --help` shows it.
- Before `page update`, it warns if the body holds `panel`, `expand`, `mention`, `emoji`, `media`, `decision` or `task-list` macros, which an update can flatten.
- `version restore` is additive: restoring v4 makes a new head version, and restores only the body, not the title, labels or parent.

After each operation it returns the page ID and title, the URL, a one-line summary (with the version number for updates) and a suggested next step.

| Exit | Meaning | Action |
|---|---|---|
| 1 | Validation | Check `--help`, fix the flag, retry |
| 2 | Auth or settings fallback | Move credentials to `.meowkit/.env` |
| 3 | Cloud-only check | The site URL is not Cloud, so use the MCP route in `install-and-auth.md` |
| 4 | Network or DNS | Retry once, check VPN |
| 5 | Permission (401 or 403) | The token may have been rotated; rerun the guided setup in `mk:confluence` |
