The confluence-search agent is the executor for `mk:confluence-search` and calls Confluence Cloud through `.claude/skills/confluence/scripts/confluence-as.sh`.

It runs on `haiku`. Tools: `Bash`, `Read`, `Grep`, `Glob`. Per-runtime model pins are on [Agent models](/guide/agent-models).

## When to use

Use it to find pages by CQL, space or label. Canonical patterns are in `.claude/skills/confluence-search/references/cql-patterns.md`.

## Rules it follows

- Every user-derived term (title, label, space-key fragment, free text) goes through `cql-sanitize.sh` before it enters a CQL string, with no trusted-input exception. The sanitizer rejects shell metacharacters and CQL statement separators and escapes backslashes and double quotes. If it exits non-zero, the agent shows you the rejection and stops until you approve a reworded term.
- `search` returns about 25 to 100 results per call (server controlled). Larger sets are paged with `--start-at` and `--max-results`, and a truncated result says "showing first N of M".
- The `--quiet` flag is not implemented in `confluence-as`, so the agent does not rely on it.

It returns the result count and a list of ID, title, space and last-modified time. For an export it returns the file path and record count.
