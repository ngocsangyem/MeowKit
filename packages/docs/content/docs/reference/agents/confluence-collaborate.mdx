The confluence-collaborate agent is the executor for `mk:confluence-collaborate` and calls Confluence Cloud through `.claude/skills/confluence/scripts/confluence-as.sh`.

It runs on `haiku`. Tools: `Bash`, `Read`, `Grep`, `Glob`. Per-runtime model pins are on [Agent models](/guide/agent-models).

## When to use

Use it to comment on a page, attach a file or manage labels and watchers. For page content use [confluence-page](/reference/agents/confluence-page).

## Rules it follows

- Footer comments are the default. It asks before it posts an inline comment (anchored to a text selection), which is more visible to anyone who can read the page.
- Attachment upload paths must be under the project root, or an allowlisted `/tmp/conf-*` prefix, with no `..` segments. The agent checks this itself and does not rely on the wrapper's check.
- A new attachment with an existing filename creates a new version of that attachment. It confirms before overwriting.
- A watcher change on a restricted page comes back as a permission error. The agent reports the status code and does not retry.
- Multi-line comments with code blocks are sent as markdown, which the wrapper converts to ADF. CQL terms are sanitized when an operation chains a CQL filter.

It returns the operation summary, the comment, attachment, label or watcher IDs and the URL.
