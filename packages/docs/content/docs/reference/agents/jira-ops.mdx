The jira-ops agent is the executor for `mk:jira-ops` and calls Jira through `.claude/skills/jira/scripts/jira-as.sh`.

It runs on `haiku`. Tools: `Bash`, `Read`, `Grep`, `Glob`. Per-runtime model pins are on [Agent models](/guide/agent-models).

## When to use

Use it when `jira-as` shows stale data, for example old field IDs after an admin change, a renamed status that search still shows by its old name, or wrong project context. It clears the cache, reruns the failing operation and reports the result. The cache TTL is otherwise self-managing.

It returns cache hit and miss stats, project metadata and a diagnostic recommendation. After `cache-clear` it returns the items cleared and a suggested next operation.
