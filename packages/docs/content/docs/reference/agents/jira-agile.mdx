The jira-agile agent is the executor for `mk:jira-agile` and calls Jira through `.claude/skills/jira/scripts/jira-as.sh`.

It runs on `haiku`. Tools: `Bash`, `Read`, `Grep`, `Glob`. Per-runtime model pins are on [Agent models](/guide/agent-models).

## When to use

Use it to move issues between sprints, manage the backlog or epics, rank issues, or read sprint and velocity totals. For story points on one ticket, see [jira-estimator](/reference/agents/jira-estimator).

## Rules it follows

- Sprint operations need a numeric `board_id`, not a project key. When you give a team or project name, it resolves the board ID first. Mixing the two is the usual cause of "board not found".
- Closing a sprint moves incomplete issues to the next sprint or back to the backlog, depending on the board. It tells you how many issues move where and asks for confirmation before it runs.

It returns the sprint ID, name, issue count and URL, or for epics the epic key and child count.
