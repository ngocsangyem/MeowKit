The jira-search agent is the executor for `mk:jira-search` and calls Jira through `.claude/skills/jira/scripts/jira-as.sh`.

It runs on `haiku`. Tools: `Bash`, `Read`, `Grep`, `Glob`. Per-runtime model pins are on [Agent models](/guide/agent-models).

## When to use

Use it to find issues by JQL, project, assignee or label. Canonical patterns are in `.claude/skills/jira-search/references/jql-patterns.md`.

## Rules it follows

- Any user-supplied term (summary text, comment text, label or component name) goes through the wrapper's sanitizer before it enters a JQL string. The sanitizer strips JQL operators, functions and special characters and quote-wraps the result. Concatenating raw input is a JQL-injection risk that can expose other teams' tickets.
- `search query` returns about 100 issues per call. Larger results are paged with `--start-at` and `--max-results`, and a truncated result says "showing first N of M".

It returns the result count and a list of key, summary and status.
