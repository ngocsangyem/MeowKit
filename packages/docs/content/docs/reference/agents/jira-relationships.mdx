The jira-relationships agent is the executor for `mk:jira-relationships` and calls Jira through `.claude/skills/jira/scripts/jira-as.sh`.

It runs on `haiku`. Tools: `Bash`, `Read`, `Grep`, `Glob`. Per-runtime model pins are on [Agent models](/guide/agent-models).

## When to use

Use it to link two issues, mark a blocker or dependency, or clone an issue.

Common link types are `blocks`, `is blocked by`, `relates to`, `clones`, `is cloned by`, `duplicates`, `is duplicated by`, `causes` and `is caused by`. Verify them per instance, since projects can define custom types.

It returns the link ID, source key, relationship, target key and URL. For a bulk link it returns the dry-run summary, the impacted count and the confirm command.
