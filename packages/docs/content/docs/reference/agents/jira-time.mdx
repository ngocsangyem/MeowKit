The jira-time agent is the executor for `mk:jira-time` and calls Jira through `.claude/skills/jira/scripts/jira-as.sh`.

It runs on `haiku`. Tools: `Bash`, `Read`, `Grep`, `Glob`. Per-runtime model pins are on [Agent models](/guide/agent-models).

## When to use

Use it to log time on an issue, view or change worklogs, set estimates or produce a time report.

## Worklog changes lose data

A worklog `update` overwrites the previous duration and a `delete` removes the entry, and Jira keeps no history of deleted worklogs. Before either one the agent reads the current worklog (`time worklogs <key>`), shows the current and proposed values and waits for your confirmation.

It returns the issue key, the new total logged, the remaining estimate and the URL.
