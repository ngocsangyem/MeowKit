The jira-collaborate agent is the executor for `mk:jira-collaborate` and calls Jira through `.claude/skills/jira/scripts/jira-as.sh`.

It runs on `sonnet`. Tools: `Bash`, `Read`, `Grep`, `Glob`. Per-runtime model pins are on [Agent models](/guide/agent-models).

## When to use

Use it to comment on an issue, attach a file or manage watchers. For issue links, see [jira-relationships](/reference/agents/jira-relationships).

## Rules it follows

- Before posting a comment that a customer or external watcher could see, it asks whether the comment is `internal` (team only) or `public`, and defaults to `internal` when unsure.
- Multi-line comments with code blocks are sent as markdown, which `jira-as` converts to ADF (Atlassian Document Format).

It returns the operation summary, the comment or attachment ID or watcher list, and the URL.
