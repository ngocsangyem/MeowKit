Athena recommends one operational decision for a hard delivery question. In supervised mode it guides a run before work starts, unblocks it when it stalls, and reads finished work against the evidence before the normal reviewer sees it. It can send work back to its executor. It cannot approve anything.

It runs on `fable` with the tools `Read`, `Grep` and `Glob`. Per-runtime model pins are on [Agent models](/guide/agent-models).

## When to use

- Pass `--advice` to a skill that documents the flag. The skill calls Athena at its named checkpoints.
- Call it directly (`@athena` where the runtime exposes direct agents) with a trade-off or judgement question. Athena reads the evidence itself and returns a strategy brief.
- Nothing routes to it from the orchestrator, a hook or a session start.

## Stages

Supervision follows `GUIDE, RESCUE*, REVIEW, RECHECK*` at named checkpoints, never per tool call or loop iteration.

| Stage | Job | Max per run |
|---|---|---:|
| GUIDE | Direction before work starts | 1 |
| RESCUE | Unblock a stalled or contradicted run | 2 |
| REVIEW | Read finished work against the evidence | 1 |
| RECHECK | Judge whether returned corrections were addressed and proven | 1 |

Each call is a fresh fork. The parent sends a packet (at most 12 KiB, at most five evidence pointers) and Athena returns a `disposition`, an assessment, one recommendation, a directive, required corrections with the proof that closes each, the cheapest falsifiable check, risks, rejected alternatives, assumptions, a confidence level and the evidence it opened, in at most 600 words.

| Stage | Legal dispositions |
|---|---|
| GUIDE, RESCUE | `CONTINUE_WITH_DIRECTIVE`, `ESCALATE_TO_HUMAN`, `BLOCKED_MISSING_EVIDENCE` |
| REVIEW, RECHECK | `READY_FOR_EXISTING_GATE`, `RETURN_TO_EXECUTOR`, `ESCALATE_TO_HUMAN`, `BLOCKED_MISSING_EVIDENCE` |

`READY_FOR_EXISTING_GATE` means the normal reviewer is the next step. It does not mean the review has passed. A second unresolved return escalates to a human.

## Direct consult

A direct call has no packet and no stage. Athena returns a brief with `situation`, `decisionRecommendation`, `nextFalsifiableCheck`, `escalationPoint` and `confidence`, plus optional rejected alternatives, risks, assumptions and evidence read. It never returns a disposition, corrections or any run field.

## Limits

- It writes nothing. On Claude Code the mutation ban is structural, because only `Read`, `Grep` and `Glob` are granted.
- It approves, clears and grades nothing. `reviewer`, `evaluator` and `security` own verdicts. Its directive is evidence a human reads, and supervision is not verification.
- It never interviews the user ([advisor](/reference/agents/advisor) does that) and never spawns another supervisor.
- It does not delay a human stop, such as `mk:fix` stopping after three failed attempts.
- It reads memory only when a packet points at an entry, and never writes it.

The parent workflow, not Athena, records each checkpoint as a receipt at `tasks/reports/{YYMMDD}-{slug}-advice-{n}.md` and keeps one compact dossier at `tasks/reports/{supervisionRunId}-athena-supervision.md`. The full contract is [`advice-supervision-rules.md`](https://github.com/ngocsangyem/MeowKit/blob/main/.claude/skills/advise/references/advice-supervision-rules.md).
