MeowKit is an AI agent toolkit for coding assistants. It installs specialist agents, skills, lifecycle hooks, security rules and a small memory store into a project, for Claude Code, Codex, Cursor, Grok, Pi and OMP. The Claude Code files live in `.claude/`, and the other runtimes get the same kit projected into the folders they read.

With the kit installed, the assistant plans before it writes and agrees the plan with you. Its changes go to adversarial reviewers, and a ship check runs lint, related tests and a type-check before any commit, push, merge or PR. The ship check refuses the command when one of them fails. Planning and review are practices in the workflow, and no hook blocks an edit or a commit on them.
