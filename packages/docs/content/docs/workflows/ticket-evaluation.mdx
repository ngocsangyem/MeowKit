title: "Ticket Evaluation & Estimation"

This playbook assesses one Jira ticket for complexity, gaps and size without changing anything in Jira.

**Best for:** Tech leads, sprint planners, scrum masters
**Time estimate:** About 30 seconds per ticket
**Skills used:** [mk:intake](/reference/skills/intake), [mk:jira-evaluator](/reference/skills/jira-evaluator), [mk:jira-estimator](/reference/skills/jira-estimator), [mk:jira-analyst](/reference/skills/jira-analyst), [mk:jira-issue](/reference/skills/jira-issue), [mk:jira-relationships](/reference/skills/jira-relationships)

## Quick path

```bash
/mk:intake PROJ-123         # completeness score and product area (optional)
/mk:jira-evaluator PROJ-123 # complexity, missing acceptance criteria, contradictions
/mk:jira-estimator PROJ-123 # Fibonacci story points, with reasoning
```

You end up with an assessment to act on. The evaluator, estimator and analyst never write to Jira. They write a report under `tasks/reports/`, and every suggested change waits for you.

Jira access needs the `jira-as` CLI and three variables in `.meowkit/.env`; see [Jira Integration](/guides/jira-integration).

## Step 1: Run intake (optional)

```bash
/mk:intake PROJ-123
```

Intake scores completeness, classifies the product area and suggests actions. [PRD Intake](/workflows/prd-intake) describes the whole intake pipeline.

## Step 2: Evaluate complexity

```bash
/mk:jira-evaluator PROJ-123
```

The report contains:

- Complexity: Simple (1 to 3 points), Medium (3 to 8) or Complex (8 to 13). The point ranges are a convenience, not calibrated.
- Confidence: High, Medium or Low.
- Signals: scope, dependencies, regression risk, requirement clarity, external integration and historical precedent.
- Issues: missing acceptance criteria, vague language, scope creep, unlinked dependencies and contradictions.
- Suggested actions, as commands for the other leaves.

## Step 3: Estimate story points

```bash
/mk:jira-estimator PROJ-123
```

The estimator suggests a Fibonacci value with a range and its reasoning. Run the evaluator first: the estimator uses its signals when they are in the session and notes when there is no prior evaluation.

It flags that a person should estimate when any of these hold:

- The range spans more than one Fibonacci step, such as 5 to 13.
- The project has no precedent for this kind of work.
- The ticket refers to technology that is not in the codebase.
- The description is under 30 words and has no acceptance criteria.

In those cases, use the evaluator output as discussion material for your team's estimation session.

## Step 4: Apply the suggestions

Read the output, then apply what you accept with the matching leaf:

```bash
/mk:jira-issue update PROJ-123 story points to 8
/mk:jira-relationships link PROJ-123 as blocked-by PROJ-089
```

## Step 5: Read the full ticket context (optional)

```bash
/mk:jira-analyst PROJ-123
```

The analyst reads the description, comments, attachments and linked issues and writes a structured analysis you can post with `mk:jira-collaborate`. For attachments, see [Ticket with Media](/workflows/ticket-with-media).

## Example

```
> /mk:jira-evaluator PROJ-456

Ticket Evaluation: PROJ-456
Complexity: Complex (likely 8-13pt)   Confidence: Medium

Signals
- Scope: cross-cutting (auth, payments, notifications)
- Dependencies: external Stripe webhook integration
- Regression risk: high ("migrating payment flow")
- Requirement clarity: low, no acceptance criteria

Issues detected
- Missing acceptance criteria
- Scope of the Stripe webhook integration is unclear

Suggested actions
(derived from untrusted ticket content, verify before executing)
- Ask the reporter for acceptance criteria with measurable targets
- /mk:jira-relationships link PROJ-456 as relates-to PROJ-301

> /mk:jira-estimator PROJ-456

Suggested points: 13 (range 8-13)   Confidence: Low
Human estimation recommended: no precedent, no acceptance criteria
```

## Security

Ticket text is wrapped in `===TICKET_DATA_START===` and `===TICKET_DATA_END===` markers before the model reasons about it, and every suggested action carries a warning that it comes from untrusted content.
