Everything that touches the shape of the project itself: creating it, configuring it, checking it is sound, and moving it forward a version.

## init — provider selection

On a **fresh install** with no provider flag, `mewkit init` opens a provider multiselect —
**Claude Code** (checked by default), **Codex**, **Cursor** — and provisions each picked
toolkit. `--target <provider>` skips the picker and keeps its own flow.

```bash
# Fresh install → provider multiselect (Claude Code preselected)
npx mewkit init

# Skip the picker — Codex-only toolkit (copies the authored Codex bundle, no .claude/)
npx mewkit init --target codex

# Skip the picker — Cursor toolkit (copies the authored Cursor bundle, no .claude/)
npx mewkit init --target cursor

# Claude Code, laid down as a plugin rather than as .claude/
npx mewkit init --target claude-code --delivery plugin
```

`--delivery` is meaningful for `--target claude-code` only; the other two targets have one shape
each, so passing it with either is refused rather than ignored. An unrecognized `--target` is
refused by name with the three valid values listed.

| Flag                  | Description                                                                                                                                        |
| --------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------- |
| `--target <provider>` | Skip the picker and create one provider toolkit. `codex` and `cursor` each copy their authored bundle (no `.claude/`, no release download); `claude-code` installs the `.claude/` kit |

**Provider multiselect** (fresh install, no `--target`):

- **Claude Code** → installs the `.claude/` kit from the latest release (today's behavior).
- **Codex** → copies the authored Codex bundle (`AGENTS.md`, `.codex/`, `.agents/skills/`); non-fatal if it can't (warns and continues).
- **Cursor** → copies the authored Cursor bundle (`AGENTS.md` plus a `.cursor/` tree of agents, rules, skills and hooks); non-fatal if it can't.
- Selecting only Codex, only Cursor, or both yields a project with no `.claude/` and no release download.
- The picker is shown for **new installs only** and only when no provider flag is passed. In update mode (existing `.claude/`), init refreshes `.claude/` without prompting; use `mewkit upgrade` to propagate to installed provider toolkits.

**Behavior:**

- `--target codex` and `--target cursor` are offline: each copies the bundle shipped in the package — no release download, no `.claude/`, no conversion. Codex fails closed if `AGENTS.md` already exists (re-run with `--force`).
- Codex and Cursor installs keep their own ledger. `mewkit upgrade` refreshes them from it, and never touches a `.cursor/` or `.codex/` directory it did not install. See [Portability](/cli/portability).

## setup

Guided post-scaffold configuration. Each step is idempotent.

```bash
mewkit setup [--only=<step>]
```

| Step        | What it does                                                    |
| ----------- | --------------------------------------------------------------- |
| `skill-envs` | Prepares the per-skill Python environments under `.meowkit/envs/<skill>/` |
| `mcp`       | Copies `mcp.json.example` → `.mcp.json`                         |
| `env`       | Creates `.meowkit/.env` for your API keys                       |
| `gitignore` | Appends MeowKit entries to `.gitignore`                         |
| `project-context` | Prints the `/mk:project-context` command to run in your first session (it writes `docs/project-context.md`) |

```bash
mewkit setup              # Run all steps
mewkit setup --only=env   # Run single step
```

## doctor

Diagnose environment issues with auto-fix for permissions.

```bash
mewkit doctor [--report] [--json] [--providers] [--state] [--hard-gates]
mewkit doctor provenance [--explain]
mewkit doctor --adopt
```

**Checks:** Node.js 24+, Python 3.9+ (optional), Git, `.claude/` structure, hooks executable, hook libraries present, memory writable, MCP config, config validity.

The Node check and `engines.node` state the same floor: Node 24, the version this project's test matrix runs. Below it the check fails and names the version it found.

**Auto-fixes:** Hook file permissions (`chmod +x`).

| Flag              | Description                                                                                            |
| ----------------- | ------------------------------------------------------------------------------------------------------ |
| `--report`        | Print shareable diagnostic report                                                                      |
| `--json`          | Machine-readable output                                                                                |
| `--providers`     | Include provider contract diagnostics                                                                  |
| `--state`         | Include state taxonomy diagnostics                                                                     |
| `--explain`       | Explain the provenance result rather than summarizing it (used with `provenance`)                      |
| `--hard-gates`    | Live-probe the hard gates: plan, privacy and injection block                                           |
| `--adopt`         | Rebuild the ownership baseline from the local kit cache, or refuse. Refused on a runtime that `mewkit-next` owns |

`mewkit doctor provenance` reports which installed files can be verified from local evidence alone, and `--explain` says what it can and cannot prove.

## upgrade

Update mewkit to the latest version.

```bash
npx mewkit upgrade [--check] [--beta] [--list]
```

| Flag        | Description                                                            |
| ----------- | ---------------------------------------------------------------------- |
| `--check`   | Show available update (shows both stable and beta)                     |
| `--beta`    | Install beta channel                                                   |
| `--list`    | List all available versions with channel info                          |

A kit release is a zip plus a `checksums.txt`. Upgrade checks the zip against that file before
extracting anything. After a `.claude/` upgrade it also refreshes any Codex or Cursor bundle this
project installed with `mewkit init --target`.

**Examples:**

```bash
npx mewkit upgrade              # Upgrade to latest stable
npx mewkit upgrade --beta       # Upgrade to latest beta
npx mewkit upgrade --check      # Check without installing
npx mewkit upgrade --list       # Show all versions
```

**Output of `--list`:**

```
Channels:
  stable:  1.2.0
  beta:    1.3.0-beta.2

Recent versions:
  1.2.0 (installed)
  1.1.1
  1.1.0
  1.0.0
```

## validate

Verify `.claude/` structure integrity.

```bash
mewkit validate
```

**Checks:** `agents/` and `hooks/` present, the 7 always-on rules present, config validity, hooks executable, docs references resolve, plugin namespace, the team-memory store. In the MeowKit authoring checkout, the full sweep also reports provider-specific vocabulary found in generic skill bodies as advisory portability WARNs; `--strict` promotes WARNs to errors. Run a focused suite with any of the flags below (no flag = the full sweep).

| Flag | Description |
| --- | --- |
| `--packs` | Pack-manifest coherence + the exact-path safety invariant. |
| `--workflow` | Workflow drift-check (always-on rules / phase docs vs `workflow.yaml`). |
| `--ownership` | Artifact ownership coverage. |
| `--substrate` | Substrate-view freshness + responsibility coverage. |
| `--rules` | Routing-table breadth. |
| `--portable` | Portable-migration manifest checks. |
| `--strict` | Promote recommended-field WARNs to errors. |

## versions

Print what this project has installed: the CLI and the kit carry
independent versions.

```bash
mewkit versions
```

Shows the CLI version, the installed kit version, the target and delivery, and how the content
arrived. Exits non-zero in a directory with no install.
