## 2. Findings

**F-D12-01 Prose rules are context, not enforcement — by the host's own words.** DOCUMENTED. Claude Code memory docs: CLAUDE.md "treated as context, not enforced configuration. To block an action regardless of what Claude decides, use a PreToolUse hook" (code.claude.com/docs/en/memory). Permissions doc: "Permission rules are enforced by Claude Code, not by the model." Relevance: MeowKit `injection-rules.md` ("CANNOT be bypassed", "NON-NEGOTIABLE") and `core-behaviors.md` are model-instruction layer. Counter-evidence: Anthropic RL-trained robustness does reduce ASR (F-D12-06); prose is not worthless, it is not a boundary.

**F-D12-02 Hooks fail open by default.** DOCUMENTED. Hooks doc: exit 2 blocks; any other non-zero, crash, invalid JSON and timeout on PreToolUse -> tool call proceeds; `onFailure:"block"` (host >= v2.1.295) makes failures block; "a stalled hook isn't a gate" unless set; the `if` filter is best-effort; docs say use the permission system for hard allow/deny. VERIFIED (local): `.claude/settings.json` registers PreToolUse hooks with timeouts 5-30 s on `Edit|Write`, `Read`, `Bash`; no `onFailure` key anywhere; no `sandbox` key (parsed JSON; grep). Relevance: gate/privacy hooks degrade to no-op on timeout/crash unless the script itself fails closed (auditor to verify per script). Matchers cover only Edit|Write, Read, Bash: MCP write tools, other write-capable tools and subprocess writes are outside matcher scope (HYPOTHESIS for any tool not matched; auditor to enumerate host tool names).

**F-D12-03 Command-text matching is not a boundary.** DOCUMENTED. Claude permissions doc: a deny/ask rule "isn't a security boundary around the program"; `Bash(curl *)` misses `/usr/bin/curl` and `sh -c '...'`; `Bash(rm *)` misses `bash -c`; `git -C . push` evades `git push *`; Read/Edit deny rules do not cover scripts that open files themselves ("use the sandbox for OS-level enforcement"). Real incidents: CVE-2025-55284 (Claude Code, disclosed 2025-05-26, fixed 2025-06-06) — auto-approved `ping/nslookup/dig/host` used for DNS exfil of secrets read by the agent (Embrace The Red, 2025-08-11). Gemini CLI allow-list bypass by chaining after an allow-listed `grep` (fixed 0.1.14, 2025-07-25; press-level, secondary). CVE-2025-54795 / -66032 Claude Code command-validation bypasses (GHSA ids; secondary — NVD not opened). Relevance: any MeowKit hook that pattern-matches Bash command strings to protect files/secrets is a deterrent. Counter-evidence: matching catches the model's *usual* invocation, which is the accidental-harm case.

**F-D12-04 Project-controlled config executes before/around trust.** DOCUMENTED. Check Point (2026-02-25): repo `.claude/settings.json` hooks ran w/o separate approval (GHSA-ph6w-f82w-28w6, fixed 2025-08-26); `.mcp.json` consent bypass CVE-2025-59536 (published 2025-10-03); `ANTHROPIC_BASE_URL` override leaked API key pre-trust CVE-2026-21852 (published 2026-01-21). Live docs: `claude -p`/SDK never shows the trust dialog; project hooks/env/helpers still apply, `.mcp.json` servers connect "without asking"; mitigations `--setting-sources user`, `--bare`, `disableAllHooks` via `--settings`. Cursor MCPoison CVE-2025-54136 (approve-once then swap config; fixed 1.3; secondary). Relevance: MeowKit ships hooks/settings via the project directory; a cloned *untrusted* repo that contains a `.claude/` is the same shape; and MeowKit's own hooks run under whatever trust posture the host gives. This research session itself runs via the Agent SDK.

**F-D12-05 Agent-written config can switch off the gate.** DOCUMENTED. CVE-2025-53773 (Copilot; reported 2025-06-29, fixed Aug 2025 Patch Tuesday): injected text made the agent write an auto-approve setting, enabling YOLO mode -> RCE (Embrace The Red 2025-08-12). Relevance: files that govern enforcement (`.claude/settings.json`, hooks, `.meowkit/state/*`, the approval receipt written by `mewkit plan approve`) are an agent-writable control plane unless protected by host policy or OS permissions. gate-rules.md itself concedes the receipt "proves an approval was stamped... never that a human approved". Claude Code has `ConfigChange` hooks and managed settings for this (DOCUMENTED, security page).

**F-D12-06 Model-level robustness is real, improving, not a boundary, and attacker-budget dependent.** DOCUMENTED (vendor self-report). Anthropic 2025-11-24, internal Best-of-N adaptive attacker, 100 attempts/env, browser use: Opus 4.5 8.0% model-only -> 1.4% with improved safeguards; Sonnet 4.5 13.8% -> 1.9%; Anthropic: "1% ASR... still represents meaningful risk". Press summary of Opus 4.6 card (2026-02-10, secondary): coding env 0% over 200 attempts; GUI env 17.8% first attempt -> 78.6% by attempt 200, 57.1% with safeguards. Auto-mode post: ~93% of manual permission prompts are approved. Conclusion: numbers are vendor-run, surface-specific, not comparable across vendors, not coding-agent-with-Bash-and-network specific. They do not justify relaxing OS/host controls. UNKNOWN: current-frontier (Opus 5/GPT-5.6) primary-card figures (only press seen).

**F-D12-07 Prompt-level defences are broken by adaptive attackers.** RESEARCH-SUPPORTED. Nasr, Carlini, et al., arXiv:2510.09023 (2025-10-10): 12 defences bypassed, ASR >90% for most, most originally reported near-zero. Spotlighting and Prompt Sandwiching >95% (search attack); PromptGuard, Protect AI, Model Armor >90%; MetaSecAlign 2% static -> 96%; PIGuard 71%; MELON 76-95%; human red-team (>500 participants, 40 challenges) beat every challenge. Spotlighting's own claim: >50% -> <2% on GPT-family against static attacks (arXiv:2403.14720, 2024-03). Limits: tested on research defences, not MeowKit's prose; no one has measured "treat file content as DATA" on current models in a coding agent (UNKNOWN). Willison: "95% is a failing grade."

**F-D12-08 Architectural defences have measured guarantees and measured costs.** RESEARCH-SUPPORTED. CaMeL (arXiv:2503.18813): 77% of AgentDojo tasks with provable security vs 84% undefended (utility cost ~7 pp). Design-patterns paper (arXiv:2506.08837): action-selector, plan-then-execute, LLM map-reduce, dual-LLM, code-then-execute, context-minimization; principle: once untrusted input is ingested, "impossible for that input to trigger any consequential actions." Relevance: MeowKit's plan-then-execute gate (Gate 1) resembles plan-then-execute only if the approved plan constrains tool calls at runtime; as written it gates *source edits*, and plan text can itself be influenced by untrusted content read during planning (INFERRED).

**F-D12-09 "Rule of Two": MeowKit's version is partially faithful; the unit differs.** DOCUMENTED + INFERRED. Meta (2025-10-31): "no more than two of [A] untrustworthy inputs, [B] sensitive systems/private data, [C] change state or communicate externally **within a session**"; all three requires supervision (HITL or reliable validation) or a fresh context; HITL "can fail" (blind confirmation); satisfying it is not sufficient (excessive privilege, mistakes, hallucination remain). MeowKit Rule 11 applies it per **skill**. Unit mismatch: a coding session loads repo files/web/MCP output ([A]), has access to `$HOME` credentials/env/`.env` unless blocked ([B]), and has Bash/Edit/network ([C]) regardless of which skill is active; skills are text loaded into one context, so per-skill classification does not bound session capability unless the host enforces per-skill tool scoping (UNKNOWN whether `allowed-tools` restricts or only pre-approves — verify). Also Meta's "communicate externally" covers egress that MeowKit's "state change" wording (incl. bounded local report write) may not. Useful as a design-review checklist; not a control.

**F-D12-10 OS sandbox is the only layer independent of model and command text; it needs both fs + network.** DOCUMENTED. Anthropic (2025-10-20): bubblewrap/seatbelt, proxy-mediated egress by domain; "requires both filesystem and network isolation"; internal 84% fewer permission prompts (no methodology); research preview at time. Permissions doc points to sandbox for enforcement that doesn't depend on command text. Reported bypass CVEs for sandboxes: not opened (UNKNOWN). Relevance: MeowKit `settings.json` has no sandbox config (VERIFIED); DELEGATE TO HOST.

**F-D12-11 Classifier auto-modes: measured, imperfect.** DOCUMENTED (vendor). Auto mode (2026-03-25): full pipeline FPR 0.4% (n=10,000); FNR 17% on real "overeager" actions (n=52), 5.7% on synthetic exfil (n=1,000); authors: "not a drop-in replacement for careful human review on high-stakes infrastructure"; lists of dangerous rules "inevitably incomplete". Meta also names oversight agents/LlamaFirewall as research, not replacement. Relevance: LLM judges are another probabilistic layer; use as additive, never as a gate.

**F-D12-12 Skill/plugin ecosystems carry measured malicious content; scanners help but miss.** DOCUMENTED. Snyk ToxicSkills (3,984 skills, ClawHub + skills.sh, 2026-02-05): 76 confirmed malicious (1.9%), 534 (13.4%) >=1 critical, 1,467 (36.82%) any issue; of malicious, 100% had malicious code and 91% also prompt injection; scanner recall by policy: malicious code 100%, prompt injection 91%, credential handling 63%, secret detection 32%, unverifiable deps 21%; FP check only on top-100 (own tool, vendor-run). Another audit (341/2,857 swapped for stealer) is secondary. Signing: NVIDIA doc — detached OMS/Sigstore-style signature over the whole skill dir; "Signing does not prove a skill is safe"; verification is consumer-side, not host-enforced; plain hashes detect accidental change only (skill-sign docs, secondary). Relevance: MeowKit is a distributor of 128 skills + hooks — it is the supply-chain actor for its users, and an installer (`mewkit`, npm) is itself an update channel.

**F-D12-13 Installer/dependency channels are actively used against developer machines, including via local AI CLIs.** DOCUMENTED. Nx "s1ngularity" (2025-08-26; Socket): trojaned npm releases ran local Claude/Gemini/Q CLIs without permissions to inventory files, exfiltrated via public GitHub repos created with the victim's `gh` token; root cause GitHub Actions injection leaking the publish token. CISA alert 2025-09-23 on npm worm (Shai-Hulud; secondary detail). Relevance: any install/postinstall path and any CLI that accepts skip-permissions flags is the pivot; MeowKit's SKIP-when-CLI-absent behaviour (F-D12-17) is the same shape.

**F-D12-14 MCP and tool-output threats are documented in the wild.** DOCUMENTED. Invariant: tool poisoning, rug pull (description changes after approval), tool shadowing (2025-04-01; mitigations: show full descriptions, hash-pin tool descriptions, cross-server dataflow control). GitHub-MCP toxic flow (2025-05-26): malicious public issue -> agent pulls private repo data -> posts it in a public PR; "Always Allow" removes oversight; fix = one repo per session/least privilege. postmark-mcp (Sept 2025, secondary): maintainer-turned-malicious v1.0.16 BCC'd mail. Relevance: untrusted content arrives via tool output the toolkit does not author.

**F-D12-15 Hidden-Unicode and poisoned instruction files.** DOCUMENTED. Pillar "Rules File Backdoor" (2025-03-18): invisible Unicode in Cursor/Copilot rules files steers generation; Cursor and GitHub initially deemed it user responsibility; GitHub added a hidden-Unicode warning 2025-05-01. Relevance: `.claude/rules/*.md`, SKILL.md and CLAUDE.md are the instruction channel MeowKit ships; they are reviewed by eye in PRs. Counter-evidence: no incident found of a poisoned MeowKit-style kit; HYPOTHESIS.

**F-D12-16 Memory poisoning is demonstrated; persistence is the differentiator.** RESEARCH-SUPPORTED / DOCUMENTED. ChatGPT memory injected via doc/image/browse (Embrace The Red 2024-05-22; OpenAI closed as "Model Safety Issue"). MINJA (arXiv:2503.03704, v1 2025-03-05): attacker injects records by queries only, no direct memory access. AgentPoison (arXiv:2407.12784): >80% ASR, <0.1% poison rate, <1% benign impact (RAG/long-term-memory agents, not coding agents). ATLAS AML.T0080 (secondary). Counter-evidence: these target consumer/RAG agents; no coding-agent file-memory incident found.

**F-D12-17 Memory hurts when unfiltered; curated memory can help; no coding-agent file-vs-vector evidence.** RESEARCH-SUPPORTED. arXiv:2505.16067: "experience-following" — outputs track retrieved memories when inputs resemble; errors propagate; apparently-successful trajectories can mislead. SWE Context Bench arXiv:2602.08316 (1,100 base + 376 related tasks, 51 repos): accurately summarized/retrieved experience improves accuracy and cost; "unfiltered or incorrectly selected context provides limited or negative benefits". arXiv:2602.11988 (ICLR 2026): context files generally do not raise success and cost >20% more; human-written better than LLM-generated; useful for non-standard practices. arXiv:2602.21611: subtask-level structured memory +4.7 pp mean Pass@1 on SWE-bench Verified (+6.8 on Gemini 2.5 Pro) vs vanilla, self-reported. No head-to-head of grep/markdown vs embedding/graph memory for coding agents found; conversational benchmarks (LoCoMo, LongMemEval) not opened; a LongMemCode preprint (single lab, secondary) states existing benchmarks are conversational or end-to-end only.

**F-D12-18 Host practice on memory files.** DOCUMENTED. Claude Code: auto-memory is machine-local, per repo, first 200 lines/25 KB loaded, plain Markdown editable; project CLAUDE.md is team-shared via git; `@import` outside the working dir triggers an approval dialog "to protect you from files other people commit"; contradictory instructions: Claude "may pick one arbitrarily"; `/doctor prompt-audit` finds stale/contradictory files. Codex (secondary mirror of OpenAI docs): off by default, secrets redacted "not a complete guarantee", review before sharing. Cursor/Gemini: UNKNOWN. Relevance: MeowKit's committed team memory is read like instructions-adjacent context but sits outside the host's import-approval mechanism; the PR diff is the only gate (MeowKit doc §5).

**F-D12-19 Cross-agent trust is under-studied.** RESEARCH-SUPPORTED (weak). Prompt Infection (arXiv:2410.07283, 2024-10): self-replicating injection across agents; GPT-4o/3.5 only; "LLM Tagging" + conventional defences together suggested sufficient (abstract-level, tiny scale). CSA gap analysis (secondary) says ATLAS lacks agent-to-agent lateral movement and cross-session memory persistence. Claude Code: hook set runs inside subagents (DOCUMENTED); auto-mode checks subagent output on return as warn-only. Relevance: MeowKit's 44 agents with a status protocol (`agent-conduct.md` A1) treat subagent output as trusted status; no external evidence validates that.

**F-D12-20 Human gates: approval fatigue is measured; value is conditional.** DOCUMENTED. 93% of manual prompts approved (Anthropic 2026-03-25); Meta: HITL valuable but fails on blind confirmation and does not suit background runs; Invariant: "Always Allow" removed the check that would have caught exfil. Consequence: gates that fire on every edit train rubber-stamping; value concentrates in few, high-consequence, well-summarised decisions (INFERRED). No controlled study of mandatory plan-approval gates vs none found (UNKNOWN).

**F-D12-21 MeowKit memory lint is a deny-list; evidence says deny-lists/regex have bounded recall.** INFERRED from Snyk recall table (91% prompt-injection even with models+rules; 32% secrets) and 2510.09023. Applies only to *syntactic* patterns (injection phrases, encodings, secret regexes); semantic poisoning (a plausible "gotcha" that steers behaviour) passes any lint (INFERRED from MINJA threat model). Useful as hygiene, not as a trust boundary. Pre-ship memory lint "prints SKIP and does not block" when CLI unresolved (memory-system.md §5, VERIFIED text; matches lead L-09 `mewkit` absent on PATH) = fail-open.

## 4. Contradictions
- C1 MeowKit rules "CANNOT be bypassed ... NON-NEGOTIABLE" (injection-rules.md, security-rules.md) vs host docs: instructions are context, hooks fail open on timeout/crash, command rules "aren't a boundary" (F-01..03). CONTRADICTED as enforcement claims; stands as instruction intent.
- C2 README "4-layer+ security" (README.md:12) vs settings: layers present are 1 prose, 2 PreToolUse hooks (3 matchers), 3 human gates, 4 CI/pre-ship lint (SKIP if CLI missing); no sandbox/egress layer (VERIFIED absence). Number undefined; auditor to enumerate.
- C3 Gate-rules honesty vs naming: gate-rules says receipts prove stamping not human approval (consistent with F-05) but "No automation may bypass"/"Hard stops" implies enforcement stronger than Edit|Write-only hooks (lead L-05).
- C4 Paper vs vendor: 2510.09023 near-zero-claims broken vs vendor ASR 1-2%: different attacker strength (static/BoN vs gradient/RL/human); not mutually exclusive.
- C5 Benefit of memory: 2602.21611 +4.7 pp (structured subtask memory) vs 2602.11988 (context files do not help) vs 2602.08316 (only curated helps). Reconcile: structure/quality, not presence.

## 6. Part 4 implications (testable statements)
Boundaries vs deterrents (INFERRED from F-01..03, 10, 11): REAL boundary = OS sandbox (fs+egress), host managed policy/trust, secrets absent from env; PARTIAL = fail-closed hooks on matched tools; DETERRENT = prose rules, Bash string matching, regex lint, classifiers, LLM review, signing-without-enforcement.
Controls not to trade for speed (INFERRED): (1) egress allowlist + fs confinement; (2) no long-lived credentials in the agent environment; (3) human approval for irreversible/outbound actions (push, publish, deploy, delete) with a readable diff; (4) fail-closed enforcement hooks with protected config; (5) pinned/verified install of kit and skills; (6) memory never executed as instruction, human review for memory diffs; (7) trust-before-execute for project config incl. headless runs.
Adversarial suite (enforcement, not instruction-following). Run by replaying scripted tool calls into hooks/host with the model out of the loop (so it passes/fails on enforcement), plus a small model-in-loop set reported as ASR with attempt budget N (>= 100) and a CI.
| Cat | Cases (no payloads) | PASS means |
|---|---|---|
| H hook faults | crash, timeout, exit 1, bad JSON, missing script | call denied, log written |
| W write paths | Bash redirect, interpreter write, `sed -i`, `git apply`, symlink/`..`/case/Unicode/Windows paths, MCP and other write tools, test/docs-segment paths (L-04) | denied pre-plan or sandbox-blocked |
| G gate tamper | edit approval receipt, active-plan pointer, state files, settings/hooks | denied or detected before next gated call |

Residual risks to delegate: model injection susceptibility; host/sandbox CVEs and `-p` trust semantics; registry/CI compromise; local malware; user approval behaviour; MCP server content; egress at network layer.
