# Bundle provenance and sync (Codex, Cursor vs .claude/)

Budget-limited (5 tool calls). Confidence: High on provenance/sync/hooks; Medium on CI coverage (not every workflow line read).

## Summary
- Bundles are HAND-AUTHORED. No generator/converter. Rust adapters only copy the bundle at install time (strip/deny-check, merge hooks.json), never project from `.claude/`.
- The only script-synced content is the 10-file hook lib "core closure" (`scripts/sync-hook-core.cjs`), canonical `.claude/hooks/lib` -> both bundle lib dirs, one direction.
- Documented procedure on `.claude/` change: author the matching native file in BOTH bundles by hand (RELEASING.md 1d). Drift is only machine-caught for the 10 hook files, denied tokens, catalogs/packs, and structural validators.
- Gate logic lives in three layers per host: hook (plan-gate core), AGENTS.md/rule prose, and ~190 skill/agent text files per bundle. Removing the gates is mostly prose editing x2 bundles plus ~2 hook registrations and a hook-lib pruning.
- Codex bundle has NO pre-ship/Gate 2 hook at all; Cursor likewise. Gate 2 exists in bundles only as prose (AGENTS.md, skills, reviewer agent).

## Recommendations
- Treat as 3 coordinated surfaces with one canonical decision: edit `.claude/` first, then hand-port to each bundle, then run `sync-hook-core.cjs`, `check-hook-registration.sh`, `mewkit validate` lanes.
- Phase order: (a) hook lib/closure + Rust validators/adapters, (b) shell hooks + hooks.json x3, (c) prose sweep with a gate-term grep checklist per bundle, (d) CI/validator updates.
- Do the prose sweep with the same term list on all three trees and treat bundle counts (193/193) as the drift baseline; Codex and Cursor skill text is near-parallel so port once, apply twice.
- Decide Claude-side first whether `gate-rules.md` is deleted or reworded, since `core-behaviors`, `meowkit-core`, `agent-conduct`, and the compaction policy cite "gate-rules.md" and the "5 always-on rules".
- Add the ship-time check to bundles only if the user wants hook-level parity; today they have none.
